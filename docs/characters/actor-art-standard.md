# Actor art standard

**Status: Existing character art rejected as permanent direction; complete redesign required.**

The locally imported **Polysplit Games Base Characters** source is approved for the initial vertical-slice implementation and playtest, including the BaseMale humanoid rig, recolor materials, and matching SwordBasic_A presentation weapon. This does **not** approve Polysplit as the permanent character style or authorize a character customization system.

## Production visual criteria

- Cohere with Townsmith, Fantasy Adventure Environment, the selected MysticDungeon subset, and available weapon families.
- Work with Unity Humanoid/Mecanim and approved Kevin Iglesias animations.
- Distinguish player, melee hostile, ranged/caster hostile, and boss at gameplay distance.
- Preserve credible weapon/hand/body proportions and clear combat actions.
- Render correctly with the project's URP setup.
- Remain presentation-only; imported art must not own Character, Combat, AI, Inventory, or persistence.
- Allow later variation where practical without requiring V1 character customization.

## Proposed review evidence

Capture representative gameplay-distance silhouettes, melee/cast poses, NPC work/idle, boss readability, and actors alongside the actual environment. Evaluate cohesion, performance, animation compatibility, license, and authoring cost.
