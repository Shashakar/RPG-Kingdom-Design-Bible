# Visual reference library

**Status: Reference system established; no new permanent visual identity approved.**

This library turns creative direction into evidence-backed visual references. It distinguishes **actual game screenshots**, **approved references**, and **exploratory inspiration**. A picture in this library does not automatically approve the assets, style, geometry, or composition it depicts.

## Current status

The initial library deliberately begins with **real source-linked project screenshots** and structured review sheets. Those images are evidence of a scene at a point in time, **not** a claim that the scene passed creative review. No external artwork has been imported without source and usage rights.

## How to use

Each reference should say what to emulate, what to avoid, what it actually proves, what remains unknown, and who approved any creative direction. See [Decision Provenance](../decisions/decision-provenance.md).
