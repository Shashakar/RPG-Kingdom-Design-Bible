# Rekindle-Claude: starting visual baseline

**Status: Implementation evidence and exploratory art direction, not final visual acceptance.**

**Primary candidate:** [Rekindle-Claude](https://github.com/Shashakar/Rekindle-Claude/tree/rekindle-vertical-slice), branch `rekindle-vertical-slice` (reference commit `548b589cdf92c59bddfd79c8d978e2a0608be1bd`). The old [RPG Kingdom](https://github.com/Shashakar/RPG-Kingdom) repository is **optional historical/reference material**, not the default implementation source. No decision has been made to replace or retain it permanently.

The Design Bible is implementation-independent. Its creative approvals apply to the intended game, not automatically to either codebase.

## Evaluation, not endorsement

The selected **stylized fantasy** direction is approved at the style-family level, with balanced mood and balanced detail. The Claude slice's specific character models, geometry, materials, lighting, and layout have **not** been approved as permanent visual standards. Use the screenshots to identify strengths and deficiencies relative to the desired game experience.

See [Art Direction](art-direction.md), [World Composition](world-composition.md), and [Visual Evidence](../decisions/visual-evidence.md).
