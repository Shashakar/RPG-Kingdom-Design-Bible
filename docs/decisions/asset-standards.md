# Existing asset and presentation standards

**Status:** Source-recorded standards; not a new creative approval.

**Source:** [RPG Kingdom asset strategy](https://github.com/Shashakar/RPG-Kingdom/blob/main/docs/ASSET_STRATEGY.md). This page is a curated cross-repository index; the source remains authoritative for exact eligibility and constraints.

| Area | Recorded selection | Qualification |
|---|---|---|
| Rendering | Unity URP | Standard |
| Settlement | HIVEMIND Townsmith: Modular Medieval Town | Approved for V1 evaluation/use; primary settlement candidate |
| Connective terrain | Fantasy Adventure Environment | Approved selectively for cliffs, rocks, foliage, and connecting spaces |
| Dungeon | Local MysticDungeon arch/column/wall subset | Selected for #79 initial slice; publisher not verified |
| World authoring | Prefab World Builder | Approved for V1 evaluation/use; editor-only |
| Combat animation | Kevin Iglesias Human Melee Animations | Approved, presentation-only |
| Humanoid animation | Kevin Iglesias Human Basic Motions | Approved, not locally imported per source |
| Work animation | Crafting Mecanim Animation Pack | Selective approval |
| UI visuals | GUI Pro - Fantasy RPG | Selective approval for frames, icons, bars, and tabs |
| Weapon art | HIVEMIND Dark Fantasy Weapons | Selective approval |

**Design implication:** Reuse these approved sources before proposing new visual dependencies. Approval of an asset is **not** approval of a finished composition, art direction, or particular placement.

The source specifies an initial environment evaluation route: **restored house → village road → forest path → dungeon entrance → dungeon room**. Evaluate visual cohesion, scale, material compatibility, navigation, performance, and damaged/restored continuity.

**Not a blanket approval:** Game Creator 2 is not a V1 foundation; networking and speculative world simulation are deferred. See the source for the complete asset register and conditions.
