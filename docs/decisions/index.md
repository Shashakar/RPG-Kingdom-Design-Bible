# Design decisions

Each decision must identify its status: **Proposed**, **Approved**, **Implemented**, **Verified**, or **Superseded**.

Approval is a human decision; implementation and verification require separate evidence.

## Decision template

```markdown
# DD-000: Title

Status: Proposed
Owner: Creative director
Date: YYYY-MM-DD
Related issues/PRs:

## Context
## Decision
## Alternatives considered
## Visual references
## Acceptance criteria
## Implementation evidence
## Supersedes / superseded by
```
