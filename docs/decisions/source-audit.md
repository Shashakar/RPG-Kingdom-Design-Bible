## Project conversation themes reviewed

The project discussion history also covers: the restoration-first vertical slice; what asset family to use after basic animations; equipment versus buildings versus terrain; Game Creator 2 as a possible future adapter rather than a V1 foundation; visual readability before polish; player health/target frames; inventory UI; future multiplayer party/area performance; agent-led Unity scene composition; and quality expectations for authored environment work.

Those themes are reflected in the relevant chapters or in the game repository's implementation/architecture documentation. **Discussion is not approval**: speculative player counts, spatial streaming thresholds, permanent art style, and Game Creator adoption remain undecided.

## Not copied into the creative bible

The game repository also includes extensive architecture, coding standards, CI, events, persistence, testing, scene-authoring protocols, system dependency maps, implementation readiness audits, and issue-specific handoffs. These are intentionally **linked, not duplicated**, because the game repository is authoritative and implementation facts change frequently.

## Remaining creative decisions

- Permanent character/enemy art identity and silhouette language.
- Cohesive world palette, materials, lighting, vegetation, and architectural treatment.
- Detailed player-origin fiction.
- UI visual style and controller usability standards beyond functional behavior.
- Final class/profession examples, mastery thresholds, and travel unlock rules.
- Performance budgets and population/streaming targets based on measured scenes.

These remain open rather than being silently canonized.
