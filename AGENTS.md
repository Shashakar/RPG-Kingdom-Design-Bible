# Agent collaboration rules

- This repository is the source of truth for approved creative and game design decisions.
- Human creative director approves changes; agents may propose changes via pull requests.
- Claude owns technical architecture in the main RPG Kingdom game repository, not creative approval here.
- Never represent a proposal or implemented feature as approved or verified without evidence.
- Record rationale, alternatives, acceptance criteria, and links to related issues/PRs.
- Do not silently supersede existing approved decisions.
